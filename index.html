LycanLoader

Cole o link do vídeo. Gere um código que instala as ferramentas e inicia o download no Windows.

Baixar um vídeo

Windows de 64 bits. Ferramentas e vídeos ficam em Downloads\LycanLoader, sem precisar de administrador.

Copie e cole no PowerShell

Abra o PowerShell, cole todo o código e pressione Enter. Ele instala o que falta, atualiza o yt-dlp com -U, verifica as ferramentas e começa o vídeo. O Deno também é preparado para compatibilidade com o YouTube.


        
      

    


    
Como funciona?
O código respeita a pasta Downloads configurada no Windows e cria LycanLoader dentro dela. Reaproveita FFmpeg e Deno dessa pasta e atualiza o yt-dlp antes de cada download. Baixa somente o vídeo informado, sem a playlist inteira.
Use links compatíveis com yt-dlp que você tem permissão para baixar. Sem suporte a login ou DRM. O link é processado no seu computador.
