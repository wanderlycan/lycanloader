# LycanLoader

Assistente web para **downloads diretos e autorizados**.

## O que ele faz

- abre links diretos de arquivos no navegador;
- gera comandos locais simples com `curl` ou PowerShell;
- orienta a abrir serviços com login no navegador oficial;
- não coleta senha, cookies ou sessões;
- não tenta extrair vídeos, streams, conteúdo offline ou mídia protegida por DRM.

## Uso

1. Cole a URL direta de um arquivo que o serviço permite baixar.
2. Confirme que você tem direito ao download.
3. Baixe no navegador ou copie o comando para seu computador.

Links que levam a players de vídeo, paywalls, telas de login ou conteúdo protegido não são compatíveis. Para serviços como Globoplay, use os recursos de download/offline oferecidos pelo aplicativo oficial, quando disponíveis.

## Privacidade

O LycanLoader é uma página estática: nenhum link, login ou arquivo é enviado para um servidor do projeto.

## Desenvolvimento

Abra `index.html` localmente ou hospede como página estática.
